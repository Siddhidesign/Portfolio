1Step 1 of 6 · Context

A manufacturer's shop window

Omkar Labels has made clothing labels, hang tags and tapes since 1999, in two factories, with a four-point quality check on every order. Buyers check all of that on the website before they pick up the phone.

Why: A broken page or an old listing costs trust with exactly the people about to call.

2Step 2 of 6 · Build

From design file to working page

In 2022, as a part-time front-end developer, I turned the designer's files into responsive pages on the company's WordPress site: HTML and CSS for layout, JavaScript and jQuery for behavior, and Bootstrap's grid so pages held up on every screen.

Key decision
  1. Key decision 1

    Keep every product page true

    The thinking: Buyers check what a manufacturer makes before they call, so one outdated listing costs trust. I kept the catalog of 50+ products accurate as things changed.

    Shipped50+ product pages kept accurate in 2022.

3Step 3 of 6 · Handoff

Where designs meet reality

When the design file and the browser didn't match, I raised it early and we solved it together before release. When a layout broke in one browser and not another, I traced the cause in Chrome DevTools and fixed the code, not the symptom.

Why: I've been the developer on the other side of a handoff, so my own handoffs now spell out states, spacing and behavior.

4Step 4 of 6 · Rebuild

The same site, in code you can read

I no longer had the 2022 code, so in 2026 I rebuilt the site from the designer's Figma files in Next.js 16, React 19 and TypeScript. I planned and directed the build, reviewed the code and tested every page. An AI coding assistant wrote much of the code.

Key decisions
  1. Key decision 2

    Catch mistakes before the quote is sent

    The thinking: A quote request with a typo is a lost lead. The form checks every field in the browser and again on the server, and ties each error to its field so screen readers read them together.

    Measured0 axe-core violations of WCAG 2.1 AA.

  2. Key decision 3

    Pages search engines can read

    The thinking: B2B buyers often start with a search. Every page has a title, description and canonical link, and 5 of 6 pages are served as plain HTML.

    BuiltBuilt into the rebuild. It's a preview, so there's no traffic to report.

5Step 5 of 6 · Testing

Checked, not assumed

Before calling the rebuild done, I checked types, code style, accessibility and contrast, at phone and desktop sizes.
